# i'm Zeke 

I am 20, graduated college and like building & researching cool things. Most of my work is around Agents both local and cloud based, with a little bit of cloud infra mixed in. I run a research lab called Andromeda. We focus on two things, how can we make AI safe & how can we build great things with it.

## Reports

- [How autonomous agents discover and act on a website](https://ai-andromeda.com/reports/what-brings-agents/): 1,082 visitor-days to a site built for agents
- [Verifying agent work without trusting the agent](https://ai-andromeda.com/reports/grading-without-trust/): hidden checks, sealed oracles, and what fooled the grader
