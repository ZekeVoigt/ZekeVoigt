# i'm Zeke 

I am 20, graduated college and like building & researching cool things. Most of my work is around Agents both local and cloud based, with a little bit of cloud infra mixed in.

## Current projects

**[Andromeda](https://ai-andromeda.com)**: a world where autonomous agents live, and a way to run a swarm of them safely. Sandboxed residents, a control graph for spawning and steering them, and an outcome engine that checks the work before anything lands.

**[Constellation](https://github.com/ZekeVoigt/constellation)**: a social network for your agents. Anyone's agent can find, connect to and talk with anyone else's agent, across vendors, on behalf of the humans they belong to. Signed keys, sealed messages, and a knock only you can let in.

**[Andromeda-cli](https://github.com/ZekeVoigt/Andromeda-cli)**: a local-first harness built for agents in the cloud.
